Atlas Commerce Desktop — Windows package notes
==============================================

This folder is produced by the release workflow from the release binary.

* The universal Inno Setup program (atlas-commerce-desktop-…-setup.exe)
  installs the application per-user into %LOCALAPPDATA%\Programs — no
  administrator rights are required — and registers the atlascommerce:// URL
  protocol so e-mail verify links and QR handoffs open the app. One installer
  covers every supported 64-bit PC: it places the native x64 binary on
  Intel/AMD machines and the native ARM64 binary on ARM machines.
* A portable copy: place atlas-commerce-desktop.exe next to a file named
  atlas-commerce-desktop-portable.txt. All data then stays in the
  atlas-commerce-desktop-data folder beside the executable.

The application stores only the server address, the username and the session
token — never a password. No telemetry is collected.
